# SyncGaze plugins for Claude

Official marketplace for **SyncGaze MCP**: connect Claude to your SyncGaze Mail.
Search, summarise and draft mail, check your domain and fix delivery problems.
Nothing is sent, deleted or changed until you approve it on SyncGaze.

## Install
- **Claude app**: Plugins, then **Add**, then **Add marketplace**, enter `SyncGaze/claude-plugins`, and install **SyncGaze MCP**.
- **Claude Code**: `/plugin marketplace add SyncGaze/claude-plugins`, then `/plugin install syncgaze-mcp@syncgaze`.

Then sign in with SyncGaze when asked and choose **Allow**.

The plugin only adds the address `https://mcp.syncgaze.in/mcp`. It contains no code.
